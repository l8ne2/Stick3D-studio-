# Stick3D Shorts Studio v2 Ultra-HD (100% Gratuit & Sans Filigrane)

Ce studio génère des vidéos Shorts / TikTok / Reels (1080×1920, 9:16, 30fps) dans le style **Stickman 2D Tête Blanche incrusté dans un décor 3D photoréaliste** !

## Nouveautés v2 (Qualité Identique à votre Image Modèle)
1. **Traduction automatique Français -> Anglais Cinéma** : écrivez vos actions en français, le studio les traduit et injecte automatiquement l'anatomie exacte *Stickman 2D tête ronde blanche sans nez + bras bâtons noirs + mains cartoon blanches + accessoires et décor 3D Unreal Engine 5*.
2. **Fiche Personnage Récurrent** : garde la même tenue (ex: chemise rouge + bretelles + casque de mineur 3D) sur tous vos plans.
3. **Moteurs d'images Ultra-HD Gratuits** :
   - **FLUX.1 (12 milliards de paramètres)** sur Hugging Face (`FLUX.1-dev`, `FLUX.1-merged`, `FLUX.1-schnell`)
   - **Google Gemini 2.5 Flash Image avec Image Modèle de Référence (`style_ref_default.jpg`)** : en collant une clé gratuite Google AI Studio (`https://aistudio.google.com/apikey` — 0€, sans carte bancaire), Gemini lit directement votre image modèle pour cloner le style au pixel près !
   - **Token Hugging Face Gratuit (`https://huggingface.co/settings/tokens` — 0€, sans carte bancaire)** : multiplie par 25 le quota quotidien gratuit sur FLUX.1 !

## Lancement sur votre PC
- **Windows** : double-cliquez sur `LANCER_WINDOWS.bat` (Python 3.10+ requis).
- **Mac / Linux** : lancez `./LANCER_MAC_LINUX.sh`.
- Le studio s'ouvre tout seul sur `http://127.0.0.1:8000` !
